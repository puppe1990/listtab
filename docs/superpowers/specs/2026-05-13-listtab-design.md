# ListTab - Design Spec

## Overview

Chrome extension alternative to OneTab. Save all open tabs into sessions, restore them individually or in bulk. Modern design with Tailwind CSS, built with TypeScript, TDD via Vitest.

## Stack

- **Language**: TypeScript (strict)
- **Framework**: React 18
- **Styling**: Tailwind CSS v4
- **Build**: Vite + @crxjs/vite-plugin (Manifest V3)
- **Testing**: Vitest + @testing-library/react + jsdom
- **Chrome**: Manifest V3, chromium-only

## Architecture

```
Extension (Manifest V3)
├── Background Service Worker (src/background/)
│   ├── TabManager        - save/restore tabs via chrome.tabs API
│   ├── SessionStore      - CRUD over chrome.storage.local
│   └── IconsGenerator    - fetch favicons via Google S2 service
│
├── Full-page Dashboard (src/dashboard/)   → chrome-extension://<id>/dashboard.html
│   ├── App.tsx           - root, global state
│   ├── SessionList       - list of saved tab groups
│   ├── SessionCard       - individual card (title, date, tab count)
│   ├── TabItem           - single tab (favicon, title, URL, restore/delete)
│   ├── SearchBar         - filter sessions/tabs
│   ├── Toolbar           - restore all, delete all, export, import
│   └── EmptyState        - zero-state when no tabs saved
│
├── Popup (src/popup/)     → chrome-extension://<id>/popup.html
│   └── PopupApp.tsx      - quick actions + recent sessions preview
│
├── Shared (src/shared/)
│   ├── types.ts          - Tab, Session, TabState
│   ├── storage.ts        - chrome.storage.local helpers
│   └── constants.ts
│
├── Assets (public/)
│   ├── icons/            - 16x16, 48x48, 128x128
│   └── manifest.json     - generated by @crxjs
│
└── Tests (src/**/__tests__/)
    ├── unit/             - pure logic tests
    └── integration/      - storage + components
```

## Data Model

```typescript
interface Tab {
  id: string            // uuid
  title: string
  url: string
  faviconUrl?: string
  pinned: boolean
  savedAt: number       // timestamp
}

interface Session {
  id: string            // uuid
  name: string          // auto-generated or user-defined
  tabs: Tab[]
  createdAt: number
  tabCount: number
  isStarred: boolean
}

interface TabState {
  sessions: Session[]
  lastBackupAt?: number
  settings: Settings
}

interface Settings {
  autoSaveOnClose: boolean
  maxSessions: number   // default 50
  confirmBeforeRestore: boolean
  darkMode: 'light' | 'dark' | 'system'
}
```

## User Flows

### 1. Save All Tabs (primary action)
1. User clicks extension icon or "Save All" button in dashboard
2. All tabs in current window are captured (title, url, favicon)
3. All captured tabs are closed
4. New session created with auto-generated name (date/time)
5. Dashboard opens showing the new session

### 2. Restore Tabs
- **Restore single**: Click a tab → opens in new tab, removes from session
- **Restore all in session**: "Restore All" button → opens all, deletes session
- **Restore all sessions**: "Restore Everything" → opens all tabs from all sessions

### 3. Manage Sessions
- **Rename**: Click session name to edit inline
- **Delete**: X button on session → confirmation if setting enabled
- **Star/Unstar**: Pin important sessions to top
- **Export**: Download sessions as JSON
- **Import**: Upload previously exported JSON

### 4. Search & Filter
- Search bar filters sessions by title, tab titles, or URLs
- Results shown in real-time as user types

## Communication Flow

```
Dashboard/Popup  ──(chrome.runtime.sendMessage)──►  Background SW
                                                   │
                                                   ├── chrome.tabs.query()
                                                   ├── chrome.tabs.create()
                                                   ├── chrome.tabs.remove()
                                                   ├── chrome.storage.local
                                                   └── fetch(favicons)
```

Background SW listens for messages:
- `saveAllTabs` → queries tabs, stores session, closes tabs
- `restoreTab` → creates tab from session data
- `restoreSession` → bulk restore
- `getSessions` → read from storage
- `deleteSession` → remove from storage
- `updateSession` → rename, star, etc.
- `exportSessions` → return JSON
- `importSessions` → merge into storage

## Error Handling

- Chrome API calls wrapped in try/catch with user-facing error messages
- Storage quota exceeded → warn user, suggest cleanup
- Invalid JSON on import → show validation error
- No tabs to save → show empty state message

## Permissions

```json
{
  "permissions": ["tabs", "storage", "activeTab"],
  "host_permissions": []
}
```

No `host_permissions` needed — we don't inject content scripts.

## Testing Strategy (TDD)

1. **Write failing test** for component/function
2. **Implement** minimum code to pass
3. **Refactor** with confidence

Test categories:
- **Unit**: Pure functions (session naming, URL validation, search filtering, data transformations)
- **Integration**: Storage operations, message passing, component rendering
- **Component**: React component behavior with @testing-library/react

Mock `chrome.*` APIs via `sinon-chrome` or custom mocks.
